# ⚽ FIFA 20 Female Player Data Analysis

## 📌 Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** of FIFA 20 Female Player data.

The objective is to analyze player attributes such as:

- Overall rating
- Potential rating
- Age distribution
- Technical skills
- Physical attributes

Through data visualization and statistical analysis, this project explores patterns in women's football player performance.

This project demonstrates **data cleaning, feature exploration, and visualization using Python.**

---

## 📊 Dataset

Dataset: **FIFA 20 Female Player Dataset**

The dataset includes attributes such as:

- Player Name
- Age
- Nationality
- Overall Rating
- Potential
- Skill Moves
- Weak Foot
- Pace
- Shooting
- Passing
- Dribbling
- Defending
- Physical

These attributes help evaluate player performance and playing style.

- Scatter plots

---

## 🔍 Key Insights

- Most players have ratings between **60 and 75**
- Younger players often show **higher potential ratings**
- Certain attributes such as **pace and dribbling strongly influence overall ratings**
- Elite players show balanced technical and physical attributes
