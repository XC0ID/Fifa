# FIFA 20 Female Player Data Analysis Report

## 1. Introduction

Sports analytics is becoming an important application of data science.  
This project analyzes a dataset of FIFA 20 female players to understand performance patterns and player attributes.

The dataset contains information about professional female football players, including their ratings, skills, and physical attributes.

The goal of this project is to explore the dataset and identify meaningful insights using data analysis techniques.

---

# 2. Dataset Description

The dataset contains multiple attributes describing each player.

Important attributes include:

- Player Name
- Age
- Nationality
- Overall Rating
- Potential Rating
- Skill Moves
- Weak Foot
- Pace
- Shooting
- Passing
- Dribbling
- Defending
- Physical

These attributes help evaluate player capabilities and playing style.

---

# 3. Data Preprocessing

Before performing analysis, the dataset was cleaned and prepared.

Steps performed:

1. Removed missing values
2. Converted numeric columns
3. Selected relevant attributes
4. Checked duplicate records
5. Standardized column names

These steps ensured the dataset was suitable for analysis.

---

# 4. Exploratory Data Analysis

EDA was performed to understand relationships between player attributes.

---

## 4.1 Distribution of Player Ratings

A histogram was used to analyze the distribution of overall ratings.

Observation:
Most players fall within the **mid-rating range (60–75)**.

---

## 4.2 Age vs Player Performance

Scatter plots were used to analyze the relationship between age and overall rating.

Observation:
Players often reach peak performance between **24 and 30 years**.

---

## 4.3 Skill Attribute Analysis

Different skill attributes were compared to understand their influence on player ratings.

Important attributes include:

- Pace
- Dribbling
- Passing
- Shooting

---

## 4.4 Correlation Analysis

Correlation heatmaps were used to identify relationships between attributes.

Observation:
Technical skills such as **dribbling and passing** show strong relationships with overall ratings.

---

# 5. Data Visualization

The project used various visualization techniques:

- Histograms

# 6. Key Insights

Important findings from the analysis include:

1. Most players have moderate ratings
2. Younger players often have higher potential
3. Technical skills strongly influence player ratings
4. Balanced attributes result in higher overall performance
