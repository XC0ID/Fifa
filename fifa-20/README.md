# ⚽ FIFA 20 Player Data Analysis

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on the FIFA 20 player dataset.  
The goal is to analyze player attributes, identify patterns, and visualize insights about player ratings, skills, and performance.

The dataset contains thousands of professional football players with attributes such as overall rating, potential, value, skill moves, and physical characteristics.

This project demonstrates **data cleaning, visualization, and statistical analysis using Python.**

---

## 📊 Dataset
Dataset: **FIFA 20 Player Dataset**

Features include:
- Player Name
- Age
- Nationality
- Club
- Overall Rating
- Potential
- Value
- Wage
- Skill Moves
- Weak Foot
- Work Rate
- Physical and technical attributes

Total Players: ~18,000+

---

## 🔍 Key Insights

- Elite players typically have **overall ratings above 85**
- Younger players often have **higher potential ratings**
- Market value is strongly correlated with **overall rating and age**
- Top clubs contain the majority of high-rated players
