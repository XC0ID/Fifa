# FIFA 20 Player Data Analysis Report

## 1. Introduction

Sports analytics has become an important field in data science.  
This project focuses on analyzing the FIFA 20 dataset to understand player attributes, performance patterns, and market value trends.

The FIFA dataset contains thousands of professional football players along with detailed performance metrics.

The goal of this project is to explore and visualize the dataset to extract meaningful insights.

---

# 2. Dataset Description

The dataset contains information about players in FIFA 20.

Important attributes include:

- Age
- Nationality
- Club
- Overall Rating
- Potential Rating
- Player Value
- Wage
- Skill Moves
- Weak Foot
- Work Rate
- Physical Attributes

Total Players: ~18,000

---

# 3. Data Preprocessing

Before performing analysis, the dataset required cleaning.

Steps performed:

1. Removed missing values
2. Converted numeric columns
3. Selected relevant features
4. Checked duplicates
5. Standardized column names

These preprocessing steps ensured the dataset was ready for analysis.

---

# 4. Exploratory Data Analysis

EDA was conducted to understand patterns in player data.

## 4.1 Distribution of Player Ratings

A histogram was used to analyze the distribution of player ratings.

Observation:
- Most players have ratings between **60 and 75**

---

## 4.2 Age vs Overall Rating

Scatter plots were used to analyze how age affects player performance.

Observation:
- Players reach peak performance between **26 and 30 years**

---

## 4.3 Top Nationalities

Count plots were used to analyze the number of players per country.

Observation:
- Countries such as **England, Spain, Brazil, and Germany** have the highest number of players.

---

## 4.4 Market Value Analysis

Player value was analyzed relative to rating and age.

Observation:
- Higher-rated players typically have significantly higher market values.

---

# 5. Data Visualization

Multiple visualization techniques were used:

- Histograms
- Countplots
- Scatter plots
- Correlation heatmaps
- Radar charts

These visualizations help identify patterns and relationships within the dataset.

---

# 6. Key Insights

Important findings include:

1. Overall rating strongly influences player value
2. Younger players tend to have higher potential
3. Most players fall within the mid-rating range
4. Top clubs recruit higher-rated players

---

# 7. Conclusion

The FIFA 20 dataset provides valuable insights into player performance and market value.

Through exploratory data analysis and visualization, we were able to identify patterns related to age, rating, and player value.

This project demonstrates how data science techniques can be applied to sports analytics.
